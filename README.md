# Akhil's Portfolio

Static portfolio site (HTML, CSS, JS). No build step needed.

## Before you upload
Open `script.js` and edit the `CONFIG` block at the top with your real email, WhatsApp number, GitHub and LinkedIn links.

## Upload to GitHub
1. Create a new repository on github.com (for example `portfolio`).
2. Click **Add file > Upload files**, drag in `index.html`, `style.css`, `script.js`, `README.md`.
3. Click **Commit changes**.

## Deploy on Vercel
1. Go to vercel.com and sign in with GitHub.
2. Click **Add New > Project** and import your repository.
3. Leave Framework Preset as **Other**, and keep the build command and output directory empty.
4. Click **Deploy**. Your site will be live at `your-project.vercel.app`.

Every future commit to the repository redeploys automatically.
